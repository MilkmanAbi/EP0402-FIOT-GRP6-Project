# ParcelGuardian Android control centre

Flutter app for the EP0402 Group 6 Uno tracker. The phone is hotspot and receiver.
See the repository README and `../docs/PHONE_SETUP.md` for pairing and use.

```powershell
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

Source: `lib/core.dart` (protocol/journal/SD parsing), `lib/controller.dart`
(receiver sessions/preferences/HTTPS relay), and `lib/main.dart` (five screens).
The receiver requires the app to stay open. Internet is optional except for
map tiles and enabled cloud relay. Android backup is disabled. The sideload APK
uses the machine's debug signing key; configure production signing for publishing.

The Gradle wrapper JAR and launch scripts are generated by `flutter create` and
are included for reproducibility. No network credentials are embedded in the app.
